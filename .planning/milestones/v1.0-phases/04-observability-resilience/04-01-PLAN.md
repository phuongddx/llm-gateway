<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Unauthenticated scraper → GET /metrics | Any network caller (Prometheus or otherwise) can read metrics without a Bearer token, per standard scrape convention |
| Authenticated client → GET /v1/chat/completions → metrics.record_request | Only an authenticated caller drives the provider/model label values metrics.py accumulates |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01-01 | Information Disclosure | main.py GET /metrics | low | mitigate | Labels restricted to provider/model/status; Task 2's no-leak test asserts no message/prompt content ever appears in rendered output |
| T-04-01-02 | Denial of Service (unbounded label cardinality / memory growth) | metrics.py in-memory dicts | low | accept | Only an authenticated caller (Bearer-gated /v1/chat/completions) drives label values; this is a single-user gateway, so cardinality growth is bounded by the operator's own request patterns, not an anonymous attacker |
| T-04-01-03 | Tampering (readiness check bypassed/spoofed) | main.py GET /health/ready | low | accept | Readiness reads only lifespan-owned in-process app.state, no external input can influence it |

</threat_model>
